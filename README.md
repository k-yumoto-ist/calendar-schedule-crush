# 📅 会議ねじこみパニック！ / CALENDAR CRUSH

「埋まりすぎたカレンダーに、さらに会議をねじ込む」をテーマにした、会社員あるある風刺パズルゲーム。

## 遊ぶ
GitHub Pages: https://k-yumoto-ist.github.io/calendar-schedule-crush/

> GitHub Pages が未有効の場合は、このリポジトリの **Settings → Pages → Build and deployment → Source: GitHub Actions** を一度だけ設定してください。以後は main ブランチの更新で自動公開されます。

## ゲームのルール
- 7日×12時間の週間カレンダーに、会議のブロックを落とします。
- 月曜〜日曜を横一列そろえると、その時間帯の予定が消滅し、上のブロックが落下します。
- 会議の種類によって、延長・ストレス増減・残務・会議削減検討会の増殖などが発生します。
- 仕事が押すと退勤見込みが遅れ、夜の私用予定との衝突イベントが発生します。
- 会社評価・家庭評価・実際の成果を両立させながら、ゲームオーバー後は最終盤面を確認できます。

## 役職と難易度
新卒 / 一般社員 / PL・リーダー / 課長 / 部長 / 役員

役職によって初期の会議件数、割り込み頻度、特殊能力が異なります。

## 技術構成
HTML / CSS / Vanilla JavaScript。依存パッケージ、ビルド工程、外部APIは不要です。GitHub Pages のサブパスでもアイコンと PWA manifest が動作するよう **相対パス** に統一しています。

- `index.html` — メタデータ・favicon・Apple Touch Icon
- `style.css` — スマートフォンとPCの1画面レスポンシブレイアウト
- `game.js` — 盤面、落下、会議効果、時間、評価、入力
- `icons/` — favicon とホーム画面用アイコン
- `site.webmanifest` — ホーム画面登録設定
- `.github/workflows/pages.yml` — GitHub Pages 自動デプロイ

### 表示について
画面は DOM / CSS グリッドで描画するため、PCで拡大してもキャンバスのような画像ぼけが起きません。高さには `100dvh` を使い、スマホのブラウザUIを考慮してスクロールしない構成です。ボタンや盤面は画面の大きさに合わせて調整されます。
